# Configuration

HelloWorldExt has **no Setup-tab connection fields**. There is no external system to connect to, so
there is nothing to configure before using the extension — add the invoker and start calling requests.

## Setup tab fields

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| *(none)* | -- | -- | This extension has no connection configuration. |

## Required vs optional

Not applicable — no fields are declared.

## Notes

- If a future version of this extension needs to call a real external system, add the connection
  `@Field.*` fields to `HelloWorldExtExtension` and document them here.
