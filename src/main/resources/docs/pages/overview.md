# Overview

HelloWorldExt is a minimal, self-contained sample extension — it is not connected to any real
third-party system. Use it to verify that a Krista extension installs, configures, and runs catalog
requests end to end, or as a template to build a real extension from.

## Use cases

- **Get a greeting** — return a "Hello, World!" message, optionally personalized with a name.

## What you can do

The extension exposes **3 requests** across **2 areas** — see [Supported Requests](pages/supported-requests.md)
for the full list, or the sidebar for each request's detailed page.

## Before you start

1. No credentials are required — see [Authentication](pages/Authentication.md).
2. The Setup tab has no configuration fields — see [Configuration](pages/ExtensionConfiguration.md).
3. Run **Test Connection** (SetUp area) to verify the extension loaded correctly.
